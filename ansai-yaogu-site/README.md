# 安塞腰鼓官网（静态站）预览说明

> 若你看到浏览器报错：`127.0.0.1 拒绝连接 (ERR_CONNECTION_REFUSED)`，通常是因为你在 **容器/远程环境** 中启动了服务，却在本机浏览器直接访问容器内的 `127.0.0.1`。

## 一键预览（推荐）

```bash
cd ansai-yaogu-site
./preview.sh
```

脚本默认：`HOST=0.0.0.0`、`PORT=4173`。

## 正确访问地址

### 场景 A：你在本机终端直接运行
访问：`http://127.0.0.1:4173`

### 场景 B：你在 Docker / WSL / 远程开发机里运行
请使用 IDE 或容器平台提供的**端口转发地址**（或先做端口映射），不要直接用容器内 `127.0.0.1`。

## 手动预览

```bash
cd ansai-yaogu-site
python3 -m http.server 4173 --bind 0.0.0.0
```

## 可选参数

- 自定义端口：`PORT=8080 ./preview.sh`
- 指定主机：`HOST=127.0.0.1 ./preview.sh`
